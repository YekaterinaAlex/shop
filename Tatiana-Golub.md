## Project Description

**Candle Shop** is a single-page online store where users can browse a catalog of handmade candles, add products to the shopping cart, change product quantities, apply a promo code, and view the order summary.

## My Contribution

I worked on the shopping cart functionality and related components.

My tasks included:

- Implementing cart state management, including adding and removing products and changing quantities.
- Implementing cart data persistence using `localStorage`.
- Developing cart-related UI components: `CartItem`, `OrderSummary`, and `CartControls`.
- Implementing the cart page and order summary updates.
- Adding the cart item counter to the header.
- Implementing promo code validation and discount calculation.
- Writing unit tests for cart functionality and components using Vitest.
- Adding promo banner and team's information to the main page.
