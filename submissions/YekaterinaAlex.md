## Project

**Candle & Co.** is an e-commerce application for browsing and purchasing candles.

The application is built with Vanilla TypeScript, Vite, HTML, and CSS.

Users can browse the product catalog, search, filter and sort products, view product details, and manage their shopping cart.

## My Contributions

- Implemented hash-based routing and navigation between pages.
- Configured CI/CD using GitHub Actions.
- Worked on project deployment.
- Developed the product catalog and product cards.
- Implemented search, filtering, and sorting functionality.
- Created Product Details pages.
- Developed reusable cart controls.
- Improved the responsive design of the catalog.
- Added unit tests using Vitest and jsdom.
